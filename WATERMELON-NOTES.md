# Watermelon-inspired interaction pass

This client-preview refinement borrows interaction principles from Watermelon UI without adopting its SaaS visual language.

Implemented:
- refined active navigation and dropdown transitions
- stronger homepage hero composition with a Mercedes-Benz spotlight
- subtle card/image/arrow micro-interactions
- progressive editorial accordions for service and export content
- responsive and reduced-motion behavior

Intentionally not changed:
- footer
- production form/backend behavior
- CI/deployment infrastructure
- verified ORBIS facts/content policy
