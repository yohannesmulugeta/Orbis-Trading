# ORBIS Trading & Technical Centre

Premium corporate website prototype for ORBIS Trading & Technical Centre Share Company, Ethiopia.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

The project uses Next.js static export. The deployable output is generated in `out/`.

## GitHub Pages

The repository includes a GitHub Pages workflow. When changes are merged into `main`,
GitHub Actions builds the site with the `/Orbis-Trading` base path and publishes it to:

`https://yohannesmulugeta.github.io/Orbis-Trading/`

## Content status

The first version uses verified information and approved imagery from the 2025 ORBIS company profile, plus legacy contact and service information from the existing ORBIS website. Vehicle inventory, prices, certifications, leadership profiles, news articles and enquiry delivery must be confirmed before final launch.
